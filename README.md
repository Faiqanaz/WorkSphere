# WorkSphere 🏢



## Office Management System



WorkSphere is a Java-based Office Management System developed to streamline and automate common office operations through an intuitive desktop application.



## 🚀 Features



\- Employee Management

\- Attendance Management

\- Team Management

\- Salary Calculation

\- Facial Recognition Attendance

\- User-friendly Desktop Interface

\- Database Integration



\## 🛠️ Technologies Used



\- Java

\- JavaFX

\- Maven

\- SQLite

\- Git \& GitHub



## 📂 Project Structure



The project follows a modular structure to maintain clean, organized, and maintainable code.



\## 🎯 Purpose



WorkSphere was developed as a Data Structures and Algorithms project to apply programming concepts and software development practices to a real-world office management scenario.
